## 512M 到底够不够，299 和 699 差在哪

这是这家最需要想清楚的地方，因为它的内存普遍偏小，512M 和 768M 占了大多数档位。

**512M 能跑什么**：单个轻量代理、一个静态站、几个定时脚本、单服务的 Docker 容器。系统本身占掉一部分之后，剩下三四百兆，跑这些东西刚好。

**512M 跑不动什么**：MySQL 加面板加两三个容器一起开，编译个稍大的项目，或者跑任何带 Java 的服务。这些场景会频繁触发 OOM，你会花大量时间调 swap 而不是用机器。
